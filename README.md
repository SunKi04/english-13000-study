# 拾词 · 英语学习手册

基于《13000英语》复习资料制作的英语学习网站，适配电脑和手机。纯静态页面，无需账号登录。

## 学习功能

- 单词查义与设备语音朗读；未收录的词可主动联网查译义。
- 155 个重点词条、130 个核心短语、60 条词缀资料。
- 30 篇练习、250 个答题位置，提交后核对参考答案。
- 生词本、笔记、记忆卡、听音拼写、释义自测与间隔复习。
- 错题本、写作模板和自动保存草稿。

## GitHub Pages

在仓库 Settings → Pages 中选择 Deploy from a branch，然后选择 main 分支及 /(root)，保存即可。网页入口为仓库根目录的 index.html。

网站不需要构建依赖，所有资源使用相对路径，可直接部署到 GitHub Pages 的项目路径下。

## 记录与发音

学习记录保存在当前浏览器的 localStorage 中。更换设备时，请在学习设置中导出和导入备份。清除浏览器数据可能清除学习记录。

单词和短语优先播放有道词典英式或美式音频，默认 0.9 倍速并保持音调；播放时会向有道发送该词条。长文和写作草稿使用经过筛选的设备英语音色，优先自然语音并排除耳语、卡通等特殊效果音。词典不可用时会提示切换。支持音色试听、重听、0.8 倍慢速重听和停止。主动联网查询会向 MyMemory 翻译服务发送当前查询的词条。

## 资料说明

练习答案来自所提供的复习资料。网站保留原文查看入口；部分排版错误在练习视图中作了规范化处理。学习时请结合上下文核对资料中的词义与答案。

## 音标与记忆提示

155 个重点词条展示美式参考音标，并有对应的美式试听按钮。词汇卡、查词详情、生词本和记忆卡共用同一份学习数据。每个词都有针对性的词族、搭配、场景、易混对比或重音提示；隐藏中文时不显示记忆提示，避免提前泄露答案。

发音数据参考 [CMU Pronouncing Dictionary](https://github.com/cmusphinx/cmudict)，在本机匹配后整理为 IPA，并按资料中的词性选择读法；部分单词存在其他读法。数据许可见 [cmudict-LICENSE.txt](cmudict-LICENSE.txt)。记忆联想是学习辅助，不等同于词源解释。
