# 拾词 · 英语学习手册

基于《13000英语》复习资料制作的英语学习网站，适配电脑和手机。纯静态页面，无需账号登录。

## 学习功能

- 单词查义与设备语音朗读；未收录的词可主动联网查译义。
- 155 个重点词条、130 个核心短语、60 条词缀资料。
- 30 篇练习、250 个答题位置，提交后核对参考答案。
- 生词本、笔记、记忆卡、听音拼写、释义自测与间隔复习。
- 错题本、写作模板和自动保存草稿。

## GitHub Pages

在仓库 Settings → Pages 中选择 Deploy from a branch，然后选择 main 分支及 /(root)，保存即可。网页入口为仓库根目录的 index.html。

网站不需要构建依赖，所有资源使用相对路径，可直接部署到 GitHub Pages 的项目路径下。

## 记录与发音

学习记录保存在当前浏览器的 localStorage 中。更换设备时，请在学习设置中导出和导入备份。清除浏览器数据可能清除学习记录。

发音由浏览器和系统的英语语音引擎提供；口音以设备实际安装的语音为准。主动联网查询会向 MyMemory 翻译服务发送当前查询的词条。
